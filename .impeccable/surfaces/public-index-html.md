# Surface: planner page (public/index.html)

Mode: Operate. Five tech-savvy students check who leads now and next, set their availability per week, swap leads, and adjust the period length. Phone first (after a push), laptop for planning.

## Direction contract

THESIS: The rota is the classroom duty board ("Tafeldienst"): who's on duty is written large on the board, the season is a chalk-ruled grid underneath. Refuses the grey SaaS table with one accent.

OWN-WORLD: Board-green ground in both colour schemes, chalk-white ink, one coloured chalk per person (yellow, pink, sky, lilac, orange) used for that person everywhere (column mark, lead block, fairness bar). Thin chalk rules, no shadows, no glass. Andika (a typeface made for learners) for names and headings, system UI for dense data, tabular numerals for weeks.

STORY: Open → see this period's lead, the next one, and when you're up. Tap your own cells to set availability. Swap a lead from the lead cell. Check fairness. Copy the WhatsApp line.
